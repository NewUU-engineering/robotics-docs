# Unitree G1 EDU — обзор

Это руководство по эксплуатации человекоподобного робота Unitree G1 EDU в поставке для Инженерной школы NewUU. Оно охватывает запуск, управление движением, калибровку, мобильное приложение, разработку на SDK, обслуживание и устранение неисправностей.

!!! danger "Сначала прочитайте раздел о безопасности"
    Аварийная остановка — ++l2+b++. Физической кнопки аварийной остановки в этой поставке нет. Прочитайте **[Технику безопасности](safety.md)** до подачи питания и проинструктируйте каждого нового оператора.

## Область применимости: прошивка

Руководство описывает **прошивку V1.0.4**. Проверьте версию прошивки в мобильном приложении в разделе **About** перед первым занятием.

!!! warning "Прошивка старше V1.0.4"
    В версиях до V1.0.4 вместо ++l2++ используется ++l1++: Zero Torque — ++l1+b++, Damping — ++l1+a++, Lock Stand — `L1+↑`. Все комбинации в этом руководстве приведены для V1.0.4.

## Старшинство источников

При расхождениях используйте источники в таком порядке:

1. **Легенда, напечатанная на самом пульте.** Документация Unitree прямо направляет операторов к этой легенде как к основному источнику.
2. **Официальная документация Unitree для вашей версии прошивки.**
3. **Это руководство.**
4. **Поставщик** — по всему, что не закрыто первыми тремя пунктами.

## Аппаратная конфигурация поставки

| Узел | Характеристика |
|---|---|
| Модель | Unitree G1, **версия EDU** (secondary development) |
| Конфигурация | **U2** — 3 DoF в талии, 7 DoF в руках |
| PC1 | Материнская плата. Отвечает за локомоцию, стабилизацию и связь с пультом и приложением. Пользователю недоступна |
| PC2 | **NVIDIA Jetson Orin NX, 100 TOPS**, заводской образ Ubuntu 20.04. Полностью доступен для вашего кода |
| PC1 ↔ PC2 | Ethernet-кабель внутри робота |
| Голова | Камера глубины **Intel RealSense D435i** и LiDAR **Livox MID-360** (360° по горизонтали, 59° по вертикали). Кабель LiDAR отсоединяется от платы; голова снимается ключом **Torx**, не шестигранником |
| Порты | 4× USB Type-C (один с DisplayPort), выход питания от батареи, pin-разъём для плат вроде Raspberry Pi, 2× RJ45 |
| Батарея | Индикатор с сегментами по 25%. Зарядное устройство 5 В. **Не взаимозаменяема с батареей Go2** |
| Уровень | Установлен сзади на новых партиях. Используется для выравнивания робота при калибровке |
| Кронштейн | Стойка с лебёдкой и стропом. Робот может ходить в подвешенном состоянии |
| Фиксаторы калибровки | Механические стопоры на талию/торс, ноги и **стопы**, плюс фиксатор камеры. Комплект для Go2 — отдельный |
| Инструмент в комплекте | Т-образный вороток и плоскогубцы |
| Пульты | Два в кейсе — для G1 и для Go2, подписаны. Все комбинации напечатаны на пульте |
| Кнопка аварийной остановки | **Не установлена.** Дистрибьютор ставит её только на готовые решения для рынков EU и US |

!!! note "Различия партий"
    Партии поставки различаются. У новых экземпляров тише и стабильнее голова, громкость голоса примерно вдвое ниже, Wi-Fi на Jetson активирован из коробки, есть уровень для калибровки, другая ревизия платы Jetson и GPIO. Проверяйте конфигурацию своего экземпляра, а не полагайтесь на общее описание.

!!! warning "Сертификация"
    Роботы этой поставки не проходят европейскую сертификацию «как есть». Большую красную кнопку сверху дистрибьютор устанавливает только на готовые продукты для рынков EU и US.

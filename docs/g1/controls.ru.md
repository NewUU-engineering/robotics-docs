# Справочник по управлению

Все комбинации на этой странице приведены для **прошивки V1.0.4**. Проверьте версию прошивки в мобильном приложении в разделе **About** перед первым занятием.

## Карта режимов

```text
   ПИТАНИЕ ВЫКЛ
        │  кнопка на батарее: одно короткое нажатие, затем удержание ≥2 с
        │  ждать ~1 минуту
        ▼
   ZERO TORQUE ─────────── суставы свободны, робот «мягкий»
        │                  доступен из любого состояния: L2+Y
        │  L2+B
        ▼
   DAMPING ─────────────── моторы обесточены. Стоящий робот УПАДЁТ
        │  TTS: "Damp mode."  В этом режиме нельзя двигать суставы руками
        │                     Это же — АВАРИЙНАЯ ОСТАНОВКА
        │  L2+↑  (Lock Stand)
        ▼
   READY ───────────────── поза удерживается, активного баланса нет
        │  TTS: "Ready mode."
        │  R2+A  (Run Control)   или   R1+Y  (Main Operation, талия 3 DoF)
        ▼                              R1+X  (для талии 1 DoF)
   MOTION ──────────────── активный баланс, управление стиками
        │  TTS: "Walk-around mode activated. Control your speed and stay alert."
        │  левый стик — вперёд/назад · правый стик — поворот
        │
        ├──► START ─────────── переключение «стоять ⇄ идти»
        ├──► 2×L2 / 2×L1 ───── низкая / высокая скорость   (в R1+X, R1+Y)
        ├──► R2+↓ / R2+↑ ───── медленный / быстрый бег      (в R2+A)
        ├──► R1+стрелки ────── компенсация смещения         (в R1+X, R1+Y)
        ├──► 2×START ───────── непрерывная ходьба — не рекомендуется
        └──► DANCE mode ────── удержание кнопки «треугольник»
                  └─ после танца → автоматически Run mode

   ПОЗЫ (удерживая L2):
      L2+A → Squat Switch        L2+← → Seated Mode
      L2+X → Lying / Standing    L2+R2 → Debug Mode

   ЛЕСТНИЦА ОСТАНОВКИ (от мягкой к жёсткой):
      1× START  → перестаёт идти, продолжает стоять    ← обычная остановка
      2× START  → прерывает выполняемое действие       ← отмена анимации
      L2+B      → Damping, медленно оседает на пол     ← АВАРИЙНАЯ
      батарея   → только если робот подвешен или сидит ← последнее средство
```

## Комбинации кнопок

| Действие | Комбинация |
|---|---|
| Питание вкл / выкл | Кнопка на батарее: одно короткое нажатие, затем **удержание ≥2 с** |
| Время загрузки | **~1 минута** до Zero Torque |
| Zero Torque | **L2+Y** |
| Damping | **L2+B** — из активного состояния комбинацию нужно **удерживать**, а не тапать |
| Lock Stand → Ready | **L2+↑** |
| Squat Switch | **L2+A** (переключатель) |
| Seated Mode | **L2+←** |
| Lying / Standing | **L2+X** |
| Debug Mode | **L2+R2** — входить, когда робот **подвешен и находится в Damping** |
| Run Control | **R2+A** |
| Main Operation Control (талия 1 DoF) | **R1+X** |
| **Main Operation Control (талия 3 DoF — наш робот)** | **R1+Y** — «Only Used For 3-DOF Waist Structure» |
| Стоять ⇄ идти | **одно нажатие START** |
| Непрерывная ходьба | **двойное нажатие START** — не рекомендуется |
| Низкая / высокая скорость | **2×L2** / **2×L1** (внутри R1+X, R1+Y) |
| Медленный / быстрый бег | **R2+↓** / **R2+↑** (внутри R2+A) |
| Наклон вперёд / назад | удержание **START+↑** / **START+↓** |
| Компенсация смещения | **R1 + стрелки** (внутри R1+X, R1+Y) |
| Рукопожатие | **SELECT+A** (удерживать SELECT, нажать A) |
| Помахать рукой | **SELECT+Y** |
| Развернуться и помахать | **SELECT+X** |
| **Аварийная остановка** | **L2+B** — робот медленно оседает на пол |
| Подъём с пола | **L2+X** |
| Dance mode | удержание кнопки **«треугольник»**; запуск танца — **R1+B** |
| Калибровка пульта | **F1+F3** → покрутить оба стика до упора по кругу → **F3** для сохранения |

!!! note "Значки на пульте"
    **Треугольник** рядом с кнопкой означает удержание. **Звезда** означает короткое нажатие.

## Режимы движения

| Режим | Вход | Характер |
|---|---|---|
| **Main Operation Control** | **`R1+Y`** для нашего робота (талия 3 DoF); `R1+X` для конфигурации с талией 1 DoF | Стабильнее, увереннее, заметно громче |
| **Run Control** | **`R2+A`** | Быстрее, походка менее устойчивая |

Unitree предписывает `R1+Y` для роботов с талией на 3 DoF: *«Only Used For 3-DOF Waist Structure»*. У нашего экземпляра талия на 3 DoF, поэтому использовать следует `R1+Y`.

!!! warning "Непрерывная ходьба"
    Двойное нажатие START включает Continuous Walking, который Unitree помечает как не рекомендованный. Не путайте с одиночным нажатием START, которое останавливает ходьбу.

## Автоматическое выключение

Робот выключается сам через **10 минут** бездействия пульта.

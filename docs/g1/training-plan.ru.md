# Учебный план

## Отработать самостоятельно

Пройдите этот список до следующей сессии. Начните с аварийной остановки и отрабатывайте её до автоматизма.

- [ ] **Аварийная остановка ++l2+b++** — отрабатывать первой, до рефлекса
- [ ] Мягкая остановка одним нажатием START
- [ ] Включение и выключение по регламенту, включая удержание ≥2 с и минуту ожидания
- [ ] Полная стартовая цепочка: `Zero Torque → L2+B → L2+↑ → R2+A`
- [ ] Переходы поз: ++l2+a++ присед, `L2+←` сидя, ++l2+x++ лёжа и стоя
- [ ] Подъём робота с пола
- [ ] Управление ходьбой, повороты, переключение скоростей (2× ++l2++ / 2× ++l1++)
- [ ] Компенсация смещения с пульта (`R1 + стрелки`)
- [ ] Интерактивные жесты (++select+a++ / `+Y` / `+X`)
- [ ] Dance mode с соблюдением требований к свободному пространству
- [ ] Подключение приложения в AP mode
- [ ] Demo Teaching — записать и воспроизвести собственный жест
- [ ] Построение LiDAR-карты и маршрута патрулирования
- [ ] Подвешивание робота на кронштейн и снятие с него

## Требует присутствия преподавателя

Без преподавателя к этому не приступать:

- Полная калибровка
- Low-level управление суставами
- Любые работы со вскрытием корпуса

## Структура занятия для преподавателя

1. Прогоните [чек-лист перед сессией](workspace.md#чек-лист-перед-сессией) до того, как студенты войдут в помещение.
2. Проинструктируйте каждую новую группу о том, [как остановить робота](safety.md#как-остановить-робота), до подачи питания.
3. Держите робота на кронштейне для всего, что выходит за рамки базовой ходьбы и жестов.
4. Освобождайте 3 м во все стороны перед Dance mode и убеждайтесь, что перед роботом никто не стоит.
5. Выключайте по регламенту: присед или подвес, проверка Damping, затем отключение питания.
